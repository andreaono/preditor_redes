O valor absoluto da latência não basta: precisamos do histórico do próprio fluxo. O baseline é o comportamento normal de cada fluxo.

O baseline vem só do Período A

A: aprende o comportamento normal; B: será classificado depois. Nenhuma linha de A entra no dataset final, nem dados de B entram no baseline (evita vazamento de dados).

Mediana: metade das medições do histórico fica abaixo e metade acima. Um valor extremo mexe pouco nela.

P95: valor abaixo do qual ficam cerca de 95% das medições deste fluxo. Acima dele, o RTT é incomum para esse histórico.

P99: valor abaixo do qual ficam cerca de 99% das medições deste fluxo. Acima dele, o RTT é muito incomum para esse histórico.

Mini-exemplo: 10, 11, 12, 13, 50 → mediana = 12. A mediana é pouco sensível a valores extremos.
